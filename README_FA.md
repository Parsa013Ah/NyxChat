# Nyx

پیام‌رسان ترمینالی خصوصی بر پایه Nostr و Tor.

[![PyPI](https://img.shields.io/pypi/v/nyxchat.svg)](https://pypi.org/project/nyxchat/)
[![Python](https://img.shields.io/pypi/pyversions/nyxchat.svg)](https://pypi.org/project/nyxchat/)
[![License](https://img.shields.io/pypi/l/nyxchat.svg)](https://pypi.org/project/nyxchat/)

## درباره

Nyx یک پیام‌رسان غیرمتمرکز و خصوصی در ترمینال است که بر پایه پروتکل Nostr ساخته شده. تمام ترافیک از طریق Tor هدایت می‌شود و از سانسور و پایش جلوگیری می‌کند. دارای رمزنگاری سرتاسری، انتقال فایل و پشتیبانی کامل از فارسی و عربی.

## ویژگی‌ها

- **پروتکل Nostr** - پروتکل غیرمتمرکز اجتماعی بدون سرور مرکزی
- **یکپارچگی Tor** - تمام ترافیک از طریق Tor برای ناشناسی
- **رمزنگاری سرتاسری** - پیام‌های مستقیم رمزنگاری شده NIP-44 v2 (NIP-17 gift wrap)
- **انتقال فایل** - ارسال و دریافت فایل با رمزنگاری AES-GCM
- **پشتیبانی فارسی/عربی** - رندر کامل متن BiDi و شکل‌دهی حروف عربی
- **چندین تم** - ۶ تم رنگی داخلی
- **پشتیبانی از پل** - دریافت خودکار پل‌های obfs4 برای مناطق سانسورشده
- **پایتون خالص** - بدون وابستگی بومی، روی ویندوز/لینوکس/مک کار می‌کند
- **سبک** - مصرف منابع حداقلی، اجرا در هر ترمینال

## نصب

### روش ۱: پکیج پایتون

```bash
pip install nyxchat
```

### روش ۲: فایل اجرایی (بدون نیاز به پایتون)

از [صفحه رلیزها](https://github.com/Parsa013Ah/NyxChat/releases) فایل اجرایی متناسب با سیستم‌عامل خود را دانلود کنید.

## کلیدها

| کلید | عملکرد |
|------|--------|
| بالا/پایین | تغییر چت |
| Enter | ارسال پیام |
| Ctrl+N | افزودن مخاطب |
| Ctrl+E | تنظیم نام نمایشی |
| Ctrl+U | تنظیم نام کاربری NIP-05 |
| Ctrl+F | ارسال فایل |
| Ctrl+D | دانلود آخرین فایل |
| F2 | تغییر تم |

| Esc/Ctrl+C | خروج |
